## [AI 智能体负载推动 CPU 复兴，AWS 面临算力紧张](https://spectrum.ieee.org/ai-cpu-comeback) ⭐️ 7.0/10

IEEE Spectrum 报道称，智能体 AI 的兴起正推动 CPU 需求新一轮增长，AWS 据称已要求工程师节约 CPU 周期，以应对服务器容量短缺。 这标志着 AI 基础设施叙事发生转变：长期被 GPU 掩盖的 CPU，在智能体 AI 的任务编排、工具调用和 API 交互中再次成为关键。超大规模云厂商可能需要重新平衡算力采购与容量规划。 文章引用分析师及 Intel、AMD 研究人员的观点称，虽然 LLM 推理仍在 GPU 上运行，但智能体工作负载会产生大量子代理，并将解析输出、调用工具、发起 API 请求等任务推给 CPU。AWS 自研的 Graviton Arm 芯片目前承载了该云厂商新增算力的一半以上。

rss · IEEE Spectrum Artificial Intelligence · 8月16日 13:00

**背景**: 智能体 AI 系统允许 AI 模型自主运行并调用子代理，常通过“工具使用”来访问互联网、文件或其他软件。虽然 GPU 加速器仍是 LLM 推理的关键，但智能体任务中的编排与工具调用层本质上依赖 CPU。AWS Graviton 是亚马逊自研的 Arm 处理器系列，已被 AWS 前 1000 名 EC2 客户中的 98%使用。

**发生了什么**: IEEE Spectrum 文章指出，智能体 AI 的兴起导致 CPU 需求激增，AWS 据报已要求工程师不惜代价节约 CPU 周期，并出现 CPU 服务器容量等待时间暴增。文章引述 Moor Insights 分析师认为 2026 年 CPU 需求上升，部分原因是智能体 AI 的大量子代理、API 调用与工具使用需要 CPU 执行。
**为什么重要**: 该信息暗示，在 AI 算力叙事中 CPU 重新变得重要。云厂商可能在 GPU 之外增加对 CPU 服务器和自研 Arm 芯片的投入，从而影响 Intel、AMD 及 Arm 服务器芯片市场的供需格局。
**影响产业链**: 若 CPU 容量紧张持续，可能影响云厂商的资本开支结构，增加对 x86 服务器 CPU 与 Arm 架构 CPU 的采购，也可能推动 AWS Graviton 等自研芯片扩产。但目前缺少具体订单或收入数据，尚无法量化对各厂商利润的影响。
