## [晶圆级亚 5 纳米单层 MoS2 晶体管突破硅极限](https://semiengineering.com/wafer-scale-sub-5nm-channel-monolayer-mos2-transistors-cmu-uf-mit-et-al/) ⭐️ 8.0/10

来自卡内基梅隆大学、佛罗里达大学、麻省理工学院、德州农工大学等机构的研究人员发表了题为《晶圆级 2D MoS2 晶体管：亚 5 纳米沟道长度与超越硅极限的亚阈值性能》的技术论文，报道了物理沟道长度低于 5 纳米、亚阈值摆幅为 88 mV/dec 的单层 MoS2 场效应晶体管。该工作表明，晶圆级二维材料器件可以在硅出现严重短沟道退化的沟道长度下仍保持可控的开关行为。 将硅晶体管沟道长度缩小到约 5 纳米以下时，短沟道效应带来的限制越来越严重，因此一种在晶圆级仍能干净开关的二维材料沟道，为后摩尔时代的低功耗逻辑器件指出了一条潜在路径。如果该工艺能够转移到商业化晶圆厂，可能影响未来逻辑技术节点以及半导体厂商的技术路线图；不过目前它仍属于早期研究成果，而非可量产的产品。 报道的亚阈值摆幅 88 mV/dec 高于室温下约 60 mV/dec 的热离子极限，因此所谓“超越硅极限”指的是在亚 5 纳米沟道长度下仍保持可用的开关特性，而非突破基本的热离子下限。该结果值得注意之处在于它是在晶圆级单层 MoS2 上实现的，而非机械剥离的薄片；但摘要节选没有提供迁移率、开态电流、器件一致性、良率或集成方面的数据。

rss · SemiEngineering · 9月22日 17:51

**背景**: MoS2 是一种二维（2D）范德华半导体，在单层形态下具有约 1.8 eV 的直接带隙和亚纳米级厚度，历史上曾被用于实现具有极高开关比和低待机功耗的晶体管。由于这种原子级厚度沟道比体硅更能抵抗短沟道效应，二维材料被广泛视为后摩尔时代电子器件的候选方向，但如何在整片晶圆上均匀生长一直是长期存在的制造难题。亚阈值摆幅衡量晶体管从关断到导通的陡峭程度，数值越低意味着器件可在更低电压下工作，而传统 MOSFET 在室温下的理论最小值约为 60 mV/dec。

## [OpenAI 为 GPT-6 升级提示缓存，新增显式断点与诊断能力](https://openai.com/index/better-prompt-caching-for-gpt-6) ⭐️ 8.0/10

OpenAI 发布官方公告，详细介绍 GPT-6 在提示缓存（prompt caching）方面的改进：更高的缓存命中率、新的诊断能力、显式缓存断点，以及用于降低延迟和成本的更多控制项。这属于面向开发者的功能优化，而不是新模型发布。 提示缓存直接影响生产环境 LLM 应用的成本与延迟曲线，因此更高的命中率和更细粒度的缓存控制，可以显著降低智能体（Agent）和 RAG 类工作负载的服务账单与首 token 延迟（TTFT），这些负载通常带有很长且稳定的提示前缀。这也有助于 OpenAI 在与 Anthropic、Google 及 vLLM 等开源推理栈的缓存方案竞争中保持优势。 根据 OpenAI 的 API 文档，开发者可以设置多个显式断点，用来保留以不同频率变化的前缀；每个请求最多可产生四次缓存写入，而顶层 instructions 以及 additional_tools 输入项目前不能包含显式断点。新增的诊断能力则把缓存行为暴露出来，让开发者能够量化命中率，而不是靠猜测判断前缀为何失效。

rss · OpenAI News · 9月22日 21:00

**背景**: 提示缓存的原理是为某段提示前缀保存模型注意力层产生的计算状态，当相同前缀再次出现时，模型便可跳过重复的预填充（prefill）计算。这样就避免了重复计算相同 token，从而为反复发送长系统提示、工具定义或文档的应用同时降低延迟和 token 成本。缓存命中率如今已与首 token 延迟一起，成为大规模运行 LLM 推理的团队的核心监控指标。
