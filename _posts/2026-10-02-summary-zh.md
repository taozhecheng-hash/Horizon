## [Nerdio CPTO Scott Manchester 谈传统 VDI 迁移僵局与将 AI 代理视为 Entra 身份](https://www.storagereview.com/news/scott-manchester-nerdio-vdi-modernization-agentic-it-governance) ⭐️ 6.0/10

在密尔沃基 EUC World Amplify 大会间隙录制的访谈中，Nerdio 首席产品与技术官 Scott Manchester 描述了导致企业长期困守传统 VDI 的“僵局”，并提议将 AI 代理视为 Microsoft Entra 中的一等身份对象，从而借助现有目录管控机制实现代理式 IT 治理。Manchester 此前在微软工作 25 年，曾负责 Azure Virtual Desktop 及后来的 Windows 365 Cloud PC，这是他加入 Nerdio 后首次系统性地公开阐述该问题。 这两个议题正在交汇：企业在将桌面迁移到云 PC 的同时，也必须决定谁——或者“什么”——有权在这些环境中执行操作，而为每个 AI 代理赋予独立身份并套用条件访问与风险检测，是少数能够复用现有企业基础设施而非另造控制平面的治理方案。若被广泛采纳，身份平台将成为企业内代理式 AI 的核心管控关口，从而影响 VDI 厂商、云桌面供应商与身份工具生态。 已发布的访谈摘录较为简短，未包含 Manchester 所描述的具体技术机制，例如代理身份如何分配、限定权限范围与审计，也未给出迁移经济性或时间表的量化数据。该内容属于厂商高管的观点阐述而非产品发布，未披露路线图时间、定价或客户承诺。

rss · StorageReview · 10月1日 18:04

**背景**: VDI（虚拟桌面基础设施）传统上在本地服务器、存储和网络栈上运行虚拟 Windows 桌面；将这些负载迁移到 Microsoft Azure Virtual Desktop（AVD）或 Windows 365 Cloud PC 等云服务时，常因应用兼容性、许可、延迟与沉没成本等问题而受阻，这正是 Manchester 所说的“僵局”。Microsoft Entra（原 Azure AD）是微软的云身份与访问管理服务，而“代理身份”指把自主 AI 代理注册到该目录中，使其拥有独立凭据，并像人类用户一样受条件访问、最小权限与风险检测策略约束。代理式 AI 治理则是指对行为具有概率性（而非完全确定性）的自主或多代理系统进行管控的新兴学科，现有的预测式 AI 治理框架并非为此设计。
